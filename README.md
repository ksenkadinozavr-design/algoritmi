# Music Archiver

Приложение принимает `.txt` файл с группами и песнями, строго валидирует формат, ищет каждый трек через YouTube Search (`yt-dlp`) и **скачивает только если найдены все песни**. Результат — один ZIP-архив с папками по группам.

## Возможности

- Строгий парсер входного файла.
- Строгий режим поиска: если хоть одна песня не найдена достаточно точно, скачивание отменяется.
- Небольшой веб-интерфейс: загрузка файла и мгновенная выдача архива.
- Архив имеет структуру:

```text
songs_archive.zip
├── Любимая группа/
│   ├── Imagine Dragons - Believer.mp3
│   └── The Weeknd - Blinding Lights.mp3
└── Спокойное/
    └── Lana Del Rey - Summertime Sadness.mp3
```

## Формат входного файла (обязательный)

```text
[Название группы]
Artist - Song title
Artist - Song title

[Другая группа]
Artist - Song title
```

Правила:

1. Каждая группа должна быть в квадратных скобках (`[ ... ]`).
2. Каждая песня только в формате `Artist - Title` (ровно разделитель ` - `).
3. Песня не может идти до первой группы.
4. Пустые строки разрешены.
5. Кодировка файла: UTF-8.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Также нужен `ffmpeg` в системе (для конвертации в mp3).

## Запуск

```bash
python app.py
```

Открыть в браузере: `http://localhost:8000`

## Как работает строгая валидация поиска

Для каждой строки `Artist - Title` выполняется запрос `ytsearch10`. Для результатов считается similarity-score (RapidFuzz) между ожидаемой строкой и комбинацией `uploader + title` из найденного видео.

- Если score ниже порога (`75`) — песня считается не найденной.
- Если хотя бы одна песня не найдена — архив не формируется, показывается список проблемных треков.
- Архив формируется только при 100% успешном сопоставлении.
