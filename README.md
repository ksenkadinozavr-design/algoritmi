# Song Archiver

Программа для пакетного скачивания песен в ZIP с **мягкой валидацией, автопоиском и автоповторами**.

## Что изменено в логике

- Валидация менее строгая: программа не падает мгновенно на первом сбое.
- Для каждой песни выполняется поиск + скачивание с повторными попытками до успеха (в пределах `max_attempts`).
- Если часть песен не скачалась, архив всё равно собирается из успешных.
- Если не скачалось ничего — будет ошибка.

## Что умеет

- читает txt-файл со списком групп и треков;
- если есть прямая ссылка (`Song | https://...`) — берёт её;
- если ссылки нет — **сама ищет трек на сайтах** через провайдеры `yt-dlp` (по умолчанию `scsearch, bandcampsearch`, без YouTube);
- скачивает в MP3 и группирует по папкам исполнителей;
- формирует единый ZIP-архив;
- даёт 2 интерфейса: CLI и веб-страницу.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Также нужен `ffmpeg` в PATH (для конвертации в mp3).

## Формат входного списка

Можно смешивать форматы:

```txt
[Кино]
Группа крови | https://site.example/track1
Пачка сигарет

ДДТ - Родина
```

- Если URL указан — используется он.
- Если URL не указан — используется автопоиск по сайтам.

Пример готового файла: `sample_songs.txt`.

## CLI запуск

```bash
python main.py --input sample_songs.txt --max-attempts 7
```

Интерактивный CLI:

```bash
python main.py --interactive
```

Параметры:
- `--input, -i` — путь к txt-файлу;
- `--output, -o` — рабочая папка (`downloads` по умолчанию);
- `--archive-name` — имя zip без расширения;
- `--proxy` — прокси: `host:port` или полный URL `http://user:pass@host:port`;
- `--proxy-user`, `--proxy-password` — логин/пароль прокси;
- `--max-attempts` — количество попыток поиска/скачивания одной песни (по умолчанию `5`);
- `--search-providers` — провайдеры поиска через запятую (по умолчанию `scsearch,bandcampsearch`, без YouTube);
- `--min-score` — оставлен для совместимости.

## Веб-интерфейс

Запуск:

```bash
python app.py
```

Откройте `http://127.0.0.1:8000`.

На странице вставьте список песен, при необходимости поправьте прокси, `max_attempts` и провайдеры поиска.
